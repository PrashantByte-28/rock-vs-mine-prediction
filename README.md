# Rock vs Mine Prediction

A machine learning project that classifies sonar signals as **Rock** or **Mine** using **Logistic Regression**.

## Dataset

The project uses the Sonar dataset containing **208 samples and 60 features**. The target classes are:

* `R` — Rock
* `M` — Mine

## Technologies Used

* Python
* NumPy
* Pandas
* Scikit-learn
* Matplotlib
* Jupyter Notebook

## Workflow

1. Load and explore the dataset
2. Encode the target labels
3. Split data into training and testing sets
4. Train a Logistic Regression model
5. Evaluate model performance
6. Predict new sonar samples

## Model Performance

* **Training Accuracy:** 82.35%
* **Test Accuracy:** 85.71%

## How to Run

Install the required libraries:

```bash
pip install -r requirements.txt
```

Then open `Rock_vs_Mine_Prediction.ipynb` and run the notebook.
